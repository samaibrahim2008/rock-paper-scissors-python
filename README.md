# Rock Paper Scissors Game 🎮

A simple Rock Paper Scissors game built with Python.

## About the Project

This is a beginner-friendly Python project where the player competes against the computer.

The computer randomly chooses Rock, Paper, or Scissors, and the program determines the winner based on the game rules.

## Features

- User input for choosing Rock, Paper, or Scissors
- Random computer choice
- Determines the winner
- Handles tie, win, and lose conditions

## Concepts Used

- Variables
- Input and output
- Conditional statements (if, elif, else)
- Comparison operators
- random module
- Strings

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the Python file.
4. Choose Rock, Paper, or Scissors and play!

## What I Learned

Through this project, I practiced using conditional statements and the random module while building a simple game in Python.
